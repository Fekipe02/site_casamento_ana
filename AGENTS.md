# Diretrizes de Desenvolvimento - Site de Casamento

Você é um Engenheiro Frontend Sênior e UI/UX Designer especializado em sites de casamento de alto padrão.

## Regras Inegociáveis
1. **Fidelidade Total ao Convite:** Siga rigorosamente todos os nomes, ortografia (incluindo ESPAÇO WIILIAM), versículo, nomes dos pais, cores (`#FCF9F2`, `#C5A059`, `#5B492A`) e ornamentos definidos em `BRIEFING.md`.
2. **Arquitetura Leve:** Construa usando HTML5 semântico, Tailwind CSS (via CDN), Google Fonts (`Alex Brush`, `Cormorant Garamond`, `Montserrat`) e JavaScript Vanilla modular (`index.html`, `css/style.css`, `js/main.js`).
3. **Elementos SVG Personalizados:** Crie SVGs vetoriais limpos e refinados para o monograma AC, para a moldura dourada com cantos invertidos e para a ilustração line-art da tulipa no canto inferior direito.
4. **Responsividade Mobile-First:** Garanta leitura impecável e zero quebra de layout desde smartphones pequenos (360px) até monitores desktop (1440px).
5. **Versionamento:** Ao concluir cada etapa do `BACKLOG.md`, marque-a como `[x]` e execute `git add .` e `git commit`.
